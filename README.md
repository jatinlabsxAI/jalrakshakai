JalRakshak AI

AI-powered flood intelligence and risk mapping for the Yamuna floodplain, Delhi.

JalRakshak AI combines satellite imagery, terrain data, rainfall, and historical river-level observations to identify flood-prone areas, estimate potential inundation, and generate location-specific flood-risk alerts.

🚀 Key Features
🛰️ Sentinel-1 SAR flood detection
🗺️ SRTM elevation & slope-based susceptibility mapping
🌧️ NASA GPM IMERG rainfall analysis
🤖 ML-based river-level prediction
📍 Location-specific flood-risk assessment
🚨 Green/Yellow/Orange/Red alert system
📊 Historical flood validation
🌐 Citizen & government-oriented dashboard
🛠️ Tech Stack

Python • Google Earth Engine • React • FastAPI • Machine Learning • GIS • Satellite Data

JalRakshak AI doesn't just tell you that a flood may happen—it shows you where the risk is.
